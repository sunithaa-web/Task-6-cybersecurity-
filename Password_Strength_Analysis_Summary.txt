Password Strength Analysis – Summary of Work

Objective: To evaluate how password complexity affects security by
creating and testing multiple passwords with different levels of
strength.

Activities Performed: 1. Created multiple passwords with varying
complexity levels. 2. Used combinations of: - Uppercase letters (A–Z) -
Lowercase letters (a–z) - Numbers (0–9) - Special symbols (!, @, #, $,
etc.) - Different password lengths 3. Tested each password using a
password strength checker. 4. Recorded the strength scores and feedback
provided by the tool. 5. Compared results to identify characteristics of
strong and weak passwords. 6. Researched common password attacks such
as: - Brute Force Attacks: Attackers try every possible combination
until the correct password is found. - Dictionary Attacks: Attackers use
lists of common words and leaked passwords to guess credentials. 7.
Documented best practices and security recommendations.

Key Findings: - Short and simple passwords received low scores and were
vulnerable to attacks. - Passwords containing only letters or common
words were easier to crack. - Longer passwords with a mix of uppercase
letters, lowercase letters, numbers, and symbols achieved higher
strength ratings. - Password length significantly improved resistance
against brute-force attacks. - Unique passwords reduced the risk of
dictionary and credential-stuffing attacks.

Best Practices Identified: - Use at least 12–16 characters. - Combine
uppercase letters, lowercase letters, numbers, and symbols. - Avoid
common words, names, dates, and predictable patterns. - Use a unique
password for every account. - Consider using passphrases and a password
manager. - Enable multi-factor authentication (MFA) whenever possible.

Conclusion: The evaluation demonstrated that password complexity and
length play a critical role in account security. Strong, unique
passwords are significantly more resistant to brute-force and dictionary
attacks, making them an essential component of cybersecurity best
practices.
